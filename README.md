# Popeye Pvc2Print

Popeye Pvc2Print by popeye marketing.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6a8d76f5ac7d6a3e09c3be74/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Popeye Pvc2Print** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6a8d76f5ac7d6a3e09c3be74/releases/latest) and reinstall.
